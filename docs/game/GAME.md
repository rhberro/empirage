# Jogo

Este documento é a porta de entrada para todas as funcionalidades do jogo, contém uma tabela que funciona como um índice com todas as funcionalidades existentes, uma breve explicação e quando consultar cada uma.

| Fluxo        | Descrição                                                                                         | Quando consultar                                                                                   | Documentação                  |
| ------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------- |
| Autenticação | Todo o processo de autenticação, desde o acesso a conta a criação e visualização dos personagens. | Quando precisar de alguma informação do processo de autenticação, criação de contas e personagens. | `docs/game/AUTHENTICATION.md` |
| Caçada | Encontros, IVs, raridade, captura e regras de balanceamento da caçada. | Sempre que a tarefa envolver encontros, raridade, IVs, captura ou configuração de locais de caça. | `docs/game/HUNTING.md` |
